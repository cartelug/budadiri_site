People's Dashboard

Commitments should have a status.

A public-facing accountability system designed to connect community needs with follow-up, parliamentary action, government response and measurable outcomes.

Dashboard rule

Issue → Commitment → Action → Result

Never publish a “100% complete” number without evidence. The production system should require an evidence link, date, responsible office and next milestone for every status update.

Data governance

No silent edits.

Every public update should retain an edit history: who changed the status, when, why and what evidence was added.

This is especially important for a website whose brand promise is accountability.
